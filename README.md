# Akila's Portfolio 

CERTIFICATIONS & ACHIEVEMENTS — DYNAMIC ORGANIZATION



I will upload my certificates and achievement documents/images later.



Do not create fake certificates or achievements.



Create a professional system in the portfolio where I can easily add certificates and achievements later.



CERTIFICATIONS



When I add certificates, organize them into separate categories/topics based on the actual certificate.



Possible categories include, but are not limited to:



- Java

- Programming

- SQL & Database

- Web Development

- Data Analytics

- Python

- Excel

- Power BI

- Artificial Intelligence / Machine Learning

- Cloud / Tools

- Other



Important:



- Do not force a certificate into an incorrect category.

- If a certificate does not clearly belong to an existing category, create an appropriate category.

- Each certificate should have:

  - Certificate title

  - Issuing organization

  - Date/year

  - Topic/category

  - Short description if useful

  - View Certificate button

- The View Certificate button should open the actual uploaded certificate/document.

- Use certificate images/PDFs provided by me.

- Do not generate or modify certificate information.

- Do not claim that I completed a course unless the uploaded certificate confirms it.



CERTIFICATE UI



Create a filter/category system so visitors can easily browse certificates.



Example:



[All] [Java] [SQL] [Web Development] [Data Analytics] [Python] [Power BI]



When a category is selected, show only certificates belonging to that category.



Use clean certificate cards with:



- Certificate image/thumbnail

- Certificate name

- Issuer

- Date

- Category

- View button



If there are many certificates, use a clean grid layout and pagination or a "Load More" option.

- Awards

Each achievement can contain:

Important:

Create category filters similar to the Certifications section.



Example:



[All] [Hackathons] [Technical] [Academic] [Competitions] [Awards]
